A Sudoku game I wrote in Rust using the [Bevy](https://bevyengine.org/) game engine. It compiles to WebAssembly with `wasm-pack`, so the whole game runs in your browser, with no server involved.

[Play it here](/play/sudoku/). It's a 20&nbsp;MB download, so give it a moment to load.
